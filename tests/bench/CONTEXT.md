# tests/bench — etl.bench harness tests

## Intent

pytest suite validating the standalone conformance & benchmark harness in the sibling `../../etl/bench/` (read-only from here): torch-optional importability, the example registry (97 examples, 3 categories, 16 tags), conformance/benchmark reports, and the CLI. Tests are the executable spec of the harness's contract — per-example failures are recorded in reports (never swallowed), so a failing test here means a real regression in etl.bench or its contract.

## Structure

| File | Contract under test |
|---|---|
| `test_import.py` | `import etl` / `import etl.bench` succeed and never pull `torch` into `sys.modules` (lazy-torch binding; no skip guards — valid in both torch-present and torch-absent environments) |
| `test_examples.py` | `list_examples()` exact 97-name registry order (op → block → e2e; counts 73/17/7); `list_categories()` == `["op", "block", "e2e"]`; `list_tags()` == the 16 first-appearance tags (micro, grad, vectorize, large, basic, control-flow, vmap, custom, xla, transformer_block, rnn, conv, mlp_block, optimization, train, infer); `get_example(name)` → frozen `Example` dataclass with the 13 documented fields in order (name/description/specs of `etl.TensorSpec`/graph/numpy_ref/torch_ref/rtol/atol/tolerance/category/inputs_fn/tags/runner) and `generate_inputs(seed)`; per-example tolerance overrides (mlp `tolerance=1e-4`; all 11 `grad_*` `rtol=atol=1e-3`; `xla_mlp` `tolerance=1e-4`; `custom_l2norm_grad`/`custom_relu2_grad` `rtol=atol=1e-3`; `matmul_1024` `atol=5e-4`, `conv2d_large` `atol=2e-4`, `vmap_mlp_large` `atol=1.2e-4`, `nbody` `atol=2e-5`, `transformer` `tolerance=1e-3`; the 3 `e2e_train_*` `tolerance=1e-3`; everything else strict defaults — incl. the 4 `e2e_infer_*`, which carry NO override); tags/runner fields (runner callable only on `e2e_train_*`); `expand_names` (in `etl.bench.examples`) precedence category → exact name → tag with exact expansion lists (e2e 7 / block 17 / grad 11 / control-flow 12 / large 6 / vectorize 6 / vmap 5); `UnknownExampleError` (ValueError subclass, message starts `unknown example 'nope'; available examples: matmul, ...`, importable from both `etl.bench` and `etl.bench.examples`); `conformance` raises it for unknown names |
| `test_conformance.py` | `conformance(...)` numpy-only full run (all 97 pass, `torch_pass is None`, every `max_abs_error < 1e-3` — worst measured ≈1.1e-4 `conv2d_large`), per-example tolerance resolution (mlp records `tolerance=1e-4`; matmul falls back to the global `None`; grad records `rtol=atol=1e-3`), grad-example smoke (transform-product staging path), tag-selection smoke (`control-flow` → 12 results, ≈0.4 s), runner-based e2e smoke (`e2e_train_mlp` → 1 result, `max_abs_error` ≈4.4e-7, ≈0.1 s — Python-level training loop over `etl.grad` graphs), `to_dict()`/`to_json()` round-trip incl. `overall_pass` and all ExampleResult field names (incl. `rtol`/`atol`/`tolerance`), `str`/`print_report` (TypeError for non-reports), single-name + `tolerance` args, torch-absent-only: `use_torch=True` → ImportError with `pip install etl[bench]` hint, auto mode skips torch; torch-present: full `use_torch=True` run passes (skips here) |
| `test_benchmark.py` | `benchmark(...)` best-of-N timing (order kept, positive ms/speedups, torch fields None when disabled), `BenchmarkReport` serialization round-trip, `str` smoke |
| `test_cli.py` | `python -m etl.bench` subprocess + in-process `main(argv)` — exit 0 ok / 2 usage error (`etl.bench: error: ...` on stderr); `--examples` selection with category → exact name → tag precedence (`grad` tag → 11 `grad_*`; `control-flow` tag → 12, ≈2 s; mixed `grad,large` tags filter the report) |
| `test_torch_repeat_calls.py` | torch-present regression pin: repeated torch-mode `conformance`/`benchmark` calls in one process all succeed (`require_torch` cache); every test gated on `pytest.importorskip("torch")` |

## Constraints

- CPU only; full numpy-only conformance of all 97 examples ≈ 10-12 s per run (the 4 full-run tests + smokes put `test_conformance.py` at ≈ 51 s; the whole `tests/bench` file suite is ≈ 67 s in torch-absent environments). The new smokes are fast: `control-flow` tag ≈ 0.4 s, `e2e_train_mlp` runner ≈ 0.1 s.
- NEVER `import torch` at module scope — only `pytest.importorskip("torch")` (first line of a function) or `importlib.util.find_spec("torch")` for environment detection (`TORCH_ABSENT`/`requires_torch_absent` pattern).
- Subprocess CLI tests run with `cwd=Path(__file__).resolve().parents[2]` (repo root) so `python -m etl.bench` finds the `etl` package; keep one subprocess per case.
- Plain `python3 -m pytest tests/bench` is green in torch-absent environments with 133 passed / 4 skipped (the torch-present conformance test + the 3 `test_torch_repeat_calls.py` torch-present regression pins); with torch installed: 135 passed / 2 skipped (the 2 torch-absent-only inverse tests). A different skip/failure count means a regression.
- Registry facts (names/categories/tags/tolerances/fields) are encoded verbatim from the live `etl.bench` registry; when examples are added/removed, regenerate the lists (see the comment above `EXPECTED_NAMES` in `test_examples.py` — `python3 -c "import etl.bench; print(etl.bench.list_examples())"`) and update this file. Two intentional registry quirks encoded in the tests: `while_fib` has **zero specs** (constant-only graph, `generate_inputs` returns `[]`); the 4 `e2e_infer_*` examples carry tags `("infer", "control-flow")` (reverses first-appearance order — tag tuples are asserted as known sub-multisets, not order-locked to first-appearance).

## Notes for agents

- `expand_names` lives in `etl.bench.examples` — it is NOT re-exported at the `etl.bench` top level (verify before importing).
- The full-suite summary line can be swallowed by nanobind/IREE finalization noise on whole-repo runs (`python3 -m pytest tests`); exit code 0 is the authoritative signal, or run `python3 -m pytest tests --co` for the collection count.
